# 드레스 견적은 어떻게 나오나 — 9월 스드메 표의 샵 21곳

조사일 2026-09-24. 스냅 리서치(`docs/야외스냅-견적-리서치.md`)와 같은 원칙 — **공개된 값과 공식 통계만** 모았다.
화면 데이터는 `data/dress.json`.

---

## 0. 결론부터

**드레스는 스튜디오보다도 가격을 안 여는 업종이다.** 스튜디오는 다이렉트결혼준비 업체 페이지에
촬영시간·씬 추가금·헬퍼비·작가지정비가 전부 적혀 있었는데, **드레스 페이지 72곳은 전부
"상품 기본정보 입니다."라는 빈 껍데기**다. 가격은 물론이고 추가금 구조도 없다.

그래서 이번엔 세 갈래로 모았다:

1. **샵의 성격** — 다이렉트 목록 페이지의 필터 태그(국내/수입 · 실크위주/비즈위주 · 우아/화려/러블리)와 주소
2. **추가금 구조** — 다이렉트결혼준비가 쓴 공식 가이드(샵별이 아니라 업계 공통)
3. **시세** — 한국소비자원 참가격 공개값 + 업계에 도는 2차 정리 + 아이웨딩 금액대 묶음

**21곳 중 대여가를 알 수 있는 곳은 5곳뿐**이고, 그 5곳의 값도 공식 발표가 아니라
플래너 한 곳(제이웨딩) 기준으로 정리된 2차 자료다. 이 한계를 안고 봐야 한다.

## 1. 가장 중요한 구조 — 묶음에 따라 드레스샵이 맡는 범위가 다르다

9월 표를 다시 보면 아래 세 묶음에만 **(토탈촬영)** 과 **(본식1회)** 가 붙어 있다.

| 묶음 | 스튜디오 | 드레스샵이 맡는 것 |
|---|---|---|
| **135만 · 160만 · 195만** | (토탈촬영) | **본식 1회만** |
| 193만 이상 | 비토탈 | **촬영 + 본식** |

즉 135/160/195만 묶음은 **촬영 드레스를 스튜디오에서 빌린다.** 그래서 이 묶음에서는
촬영 드레스 벌 수 추가·라벨 업그레이드가 **드레스샵이 아니라 스튜디오 가격표**에 붙는다.

스냅 리서치에서 긁어 둔 스튜디오별 촬영 드레스 추가금이 그대로 이 묶음의 드레스 예산이다:

- ST정우(우정우): 드레스 추가 **불가**, 캐주얼 1벌 5만, 시그니처라벨 10~30만
- 더청담: 드레스 업그레이드 11~33만, 턱시도 11만
- 어반스튜디오: 드레스 추가 11~33만, 업그레이드 11~22만
- 가을스튜디오: 화이트 16.5만 / 빈티지 11만 / 블랙라벨 22만
- 헤로하우스: 1벌 22만, 시그니처 11~33만, 유색 11~22만
- 이포토에세이: 드레스 추가 11만, 프리미엄 16.5~33만, 한복 세트 22만
- 로에빈: 드레스 추가·업그레이드 각 11~33만, **외부 드레스 반입 11만**(토탈이면 반입 불가)

**토탈로 계약하면 외부 드레스를 아예 못 들고 가는 스튜디오가 많다**(로에빈·원규·어반).
"드레스샵에서 촬영 드레스까지 하고 싶다"면 193만 이상 묶음을 봐야 한다.

## 2. 추가금 구조 — 기본 구성은 촬영 3벌 + 본식 화이트 1벌

다이렉트결혼준비의 공식 가이드와 FAQ에서 확인한 항목들.

| 항목 | 금액 | 언제 붙나 |
|---|---|---|
| **드레스 투어 피팅비** | 샵당 **5.5만~** | 방문하는 샵마다 각각. 3곳 돌면 15~20만. 투어 당일 샵을 정하면 이후 촬영가봉·본식가봉엔 대개 없다 |
| **재가봉 피팅비** | 샵마다 다름 | 본식가봉 뒤 체형 변화·디자인 변경으로 다시 볼 때 |
| **라벨 업그레이드** | **30만 ~ 200만** | 기본 패키지는 일반 라벨 기준. 블랙라벨·프리미엄·수입으로 올릴 때 |
| **퍼스트웨어** | 샵마다 다름 | 아무도 안 입은 새 드레스(첫 착용). 신상·새로 들어온 드레스면 붙는 경우가 많다 |
| **2부 드레스** | 별도 추가금 | 당일지정혜택으로 서비스하는 샵도 있지만 대부분 유료 |
| **헬퍼비 (촬영)** | **25만** | 야외·5시간 초과·2부 드레스·서울 외 지역이면 +5만~ |
| **헬퍼비 (본식)** | **25만** | 촬영과 별도로 한 번 더 |
| **외부 드레스 반입** | 11만~ | 스튜디오에 다른 데서 빌린 드레스를 들고 갈 때 |

다이렉트 FAQ 원문: *"기본라벨(베이직)로 촬영드레스(3벌) & 본식드레스(화이트 1벌) 선택 시 별도의 추가 비용은 없습니다.
기본 제공에서 촬영드레스 추가, 본식 2부 드레스 추가, 드레스라벨 업그레이드 등 선택 시 추가비용이 발생합니다.
추가비용은 드레스샵에 따라 다르며, **보통 각 최소 30만원부터**입니다."*

투어 실무: 샵당 **4벌 피팅 + 헤어세팅 40~50분**, 청담 안에서 샵 간 이동 10~15분.
평균적으로 투어 때 샵당 4벌 입고 1~2벌 홀딩, 촬영가봉 때 6벌 입고 3벌 홀딩,
본식 셀렉 때 홀딩분에 2~3벌 더 입어 총 4벌 중 1벌을 고른다.
**10~15분 이상 지각하면 피팅 자체가 어려울 수 있고, 위약금을 물리거나 일정이 취소되는 샵도 있다.**

## 5. 투어 때 물어볼 것

1. **투어 피팅비 얼마인가요?** (샵당 5.5만이 기본선)
2. **재가봉 비용이 있나요?** 있다면 얼마인가요?
3. **라벨 구조가 어떻게 되나요?** 기본/블랙/프리미엄/수입 각각 추가금은?
4. **제가 고른 이 드레스가 퍼스트웨어인가요?** 그러면 얼마가 붙나요?
5. **2부 드레스 포함인가요, 별도인가요?** 별도면 기준이 뭔가요?
6. **당일지정혜택이 뭔가요?** (보통 블랙라벨 무료 업그레이드 / 투어 때 홀딩한 드레스 추가비용 면제 / 라벨별 할인)
7. 헬퍼비는 촬영·본식 각각 25만이 맞나요? **야외 촬영이면 얼마나 올라가나요?**
8. (135·160·195만 묶음이면) **촬영 드레스는 스튜디오 것을 쓰는 게 맞죠?** 그 추가금은 스튜디오에 물어봐야 하나요?
