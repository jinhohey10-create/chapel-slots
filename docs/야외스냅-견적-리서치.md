# 야외 스냅 견적은 어떻게 나오나 — 항목 분해와 실제 시세

조사일 2026-09-22. 모두 **공개된 가격표**만 모았다(업체 홈페이지 / 다이렉트결혼준비 업체 페이지 / 오딩 스냅 상품 페이지 / 크몽·숨고 공개가).
상담을 통해서만 나오는 숨은 가격은 여기 없다. 원자료는 `docs/data/snap_travel_fees.csv`(21개 업체 × 지역 762행, 상품별 값이 다르면 최저/최고로 표기), `docs/data/snap_products.csv`(79개 상품).

---

## 1. 한 줄 요약

야외 스냅 견적은 **촬영비 + 출장비 + 데이터비 + 사람값(헬퍼·헤메) + 의상 + 장소**로 쪼개진다.
서울 작가 기준 촬영비는 2시간 25~40만 / 4시간 70만 / 6시간 100만 선이고,
**출장비는 권역별로 거의 표준화돼 있다 — 경기 5만, 충청 15만, 강원 20만, 전라 22만, 경상 25만(중앙값).**
**제주는 어느 업체 출장비 표에도 없다.** 항공·숙박이 붙는 별도 견적이라, 실무에서는 제주 현지 작가를 쓰는 게 기본이다(3시간 40만 / 4시간 45만 / 5시간 60만).

## 2. 견적서를 쪼개면 이 8줄이다

| # | 항목 | 무엇 | 실제 금액대 |
|---|---|---|---|
| 1 | **촬영비(작가료)** | 시간 × 작가 수(메인 1인 / 메인+서브 2인) | 2h 25~40만 · 3h 65만 · 4h 70만 · 5~6h 100만 |
| 2 | **출장비** | 서울 밖으로 나가는 값. 권역·도시별 고정표 | 경기 0~20만 · 강원 0~35만 · 충청 0~30만 · 전라 0~45만 · 경상 0~50만 |
| 3 | **데이터비** | 원본 / 수정본 / RAW | 원본+수정본 **44~55만** · RAW 별도 11~27.5만 |
| 4 | **헬퍼비** | 드레스 입히고 챙겨주는 이모님 | 촬영 25만 + 본식 25만. 야외·5시간 초과·2부드레스·서울 외 지역이면 **+5만~** |
| 5 | **헤어·메이크업** | 샵 진행 or 출장 | 얼리스타트(대개 오전 8시 이전, 샵마다 다름) **+11만~**, 헤어변형 1회 5.5~11만 |
| 6 | **의상** | 드레스 벌수 추가 / 라벨 업그레이드 / 외부 반입 | 벌당 11~33만 · 외부 드레스 반입 11만 · 스몰웨딩 드레스 단독 대여 22만~ |
| 7 | **장소** | 로케이션 대관·입장료 | 라흐 '물의정원' 로케 33만 같은 식 |
| 8 | **결과물** | 앨범·액자·인화·폴라로이드·익스프레스 보정 | 액자 5~12만 · 보정 익스프레스 10만 · 보정본 추가 1장 1만 |

VAT는 스냅 업체 대부분 **별도**, 스튜디오 정찰제는 **포함**인 경우가 많다. 표기를 꼭 확인할 것.

읽히는 규칙 세 가지:

1. **촬영비가 비싼 업체일수록 출장비도 비싼 경향.** 프리즘홀(본식 60~90만)·빌링스(55~100만)는 강원 30~35만, 경상 45~50만. 다만 절대 규칙은 아니다 — 강산픽은 본식 90~98.5만인데 전국 11~22만으로 낮게 고정해 둔다.
2. **"출장비 0원"을 내세우는 업체가 실제로 있다**(애프터스튜디오, 루스모먼트). 전국 동일가 정책.
3. **강원 ≒ 충청+5~10만, 경상·전라 ≒ 강원+5만.** 사용자가 예로 든 강원도/충청도는 중간 구간이고, 진짜 비싸지는 건 경상·전라·제주다.

### 3-3. 제주는 왜 표에 없나

21개 업체 2,695행 중 **제주 항목은 0건**. 즉 서울 작가에게 제주는 "표로 파는 지역"이 아니라 개별 견적이다. 붙는 것들:

- 왕복 항공 (메인작가 1인, 2인 촬영이면 서브까지 2인)
- 최소 1박 숙박 (예식·촬영 시각상 전날 입도가 사실상 필수)
- 렌터카 / 현지 이동
- 작가의 하루 통째 구속 비용

그래서 제주는 **현지 작가**를 쓰는 게 정석이고, 현지 정찰제는 육지보다 오히려 싸다:

| 제주 현지 (댕귤스튜디오, 크몽 공개가) | 구성 | 가격 |
|---|---|---|
| 삼댕귤해 | 3시간, 장소 3곳, 색감보정 원본 500컷+, 세부보정 20컷, 수정 1회 | **40만원** |
| 사댕귤해 | 4시간, 장소 4곳, 원본 600컷+, 세부보정 20컷, 수정 2회 | **45만원** |
| 오댕귤해 | 5시간, 장소 5곳, 원본 700컷+, 세부보정 30컷, 수정 2회 | **60만원** |

다른 제주 업체(재나스냅)도 시간제 정찰제: 1h 13만 / 2h 23만 / 3h 35만 / 4h 46만 / 5h 55만 (초상권 동의 기준, 미동의 시 각 +2~5만).
초상권 동의 여부로 가격이 갈리는 건 제주 스냅 업계의 흔한 구조다.

## 4. 야외 스냅 촬영비 실제 시세

오딩 '야외 스냅' 카테고리 전량 + 리허설 촬영 (모두 VAT 별도):

| 업체 | 상품 | 시간 | 구성 | 가격 |
|---|---|---|---|---|
| 빌라드블랑스냅 | 데이트스냅 / 한복스냅 | 2h(평일) | 원본+수정본, 5R 인화 10장, 포토박스 | **25만** |
| 달보드레스냅 | 야외 데이트 스냅 | 2h | 원본 전체 색감보정 + 세부수정 40장, 의상 2벌, 원본비·셀렉비 없음 | **40만** |
| 빌리에또 | 데이트스냅 | 2h | 원본 + 보정 20컷 + 5×7 인화 10장, 서울/경기 내 | **40만** |
| 빌링스 스튜디오 | 자연광 스튜디오 리허설 | 2h | 원본 전체 톤보정 + 수정 15장, 의상 개별준비, 헤메 불포함 | **40만** |

| 프리즘홀 | 대표작가 야외스냅 | 3h | 원본 800~1000장 색감보정 + 수정 20장, 의상 3벌, 장소 협의 | **65만** |
| 강산픽 | 야외&하우스웨딩 | **4h** | 세부보정 20 + 색감보정 50 + 원본 전체 + 흑백 30장 | **70만** |
| 강산픽 | 야외&하우스웨딩 | **6h** | 세부보정 30 + 색감보정 100 + 원본 전체 + 흑백 30장 | **100만** |

비교용 본식스냅 시세(같은 플랫폼 31개 상품): 최저 35만 / **중앙값 72만** / 최고 110만.
→ **4시간짜리 제대로 된 야외스냅 = 본식스냅 1건과 비슷한 값**이라고 보면 감이 맞다.

플랫폼 평균치(참고): 숨고 웨딩스냅 평균 32.7~40만, 강릉 지역 평균 38.9만(최저 29.7만~최고 70만).

### 강산픽 야외스냅 추가금 (공개돼 있어 구조 참고용으로 좋다)

- 인원(반려견) 추가 5만 / 폴라로이드 10장 3.5만 / 원목액자 small 5만·big 9만·세트 12만
- 보정 익스프레스 10만 / 보정본 1장 추가 1만
- SNS 활용 동의 시 **5만 할인** 또는 필름카메라 1롤
- **헤어메이크업·의상·소품 불포함** ← 야외스냅 상품의 기본 전제
- 원본·색감보정본 14일 내, 세부보정본은 셀렉일 기준 30일 내

## 5. 그래서 "서울 작가 + 지방 로케" 총액은?

공개 단가만 더한 것. 헤메·의상은 따로 붙는다.

**(A) 강릉 4시간 야외스냅 — 중급 작가**
```
촬영비 4h                70만
출장비 강원                20만   (중앙값)
소계                      90만
VAT 10%                    9만
─────────────────────────────
                        약 99만원
```

**(B) 대전 3시간 — 대표작가급(프리즘홀)**
```
촬영비 3h                65만
출장비 충청(프리즘홀)      30만
VAT                      9.5만
─────────────────────────────
                      약 104.5만원
```

**(C) 제주 4시간 — 현지 작가**
```
촬영비 4h(댕귤)           45만
출장비                     0원   (현지)
─────────────────────────────
                        약 45만원
+ 우리 둘의 항공·숙박은 어차피 드는 비용
```

**(D) 제주 4시간 — 서울 작가 출장**: 촬영비 70만 + **개별 견적**.
공개된 표가 없어 숫자를 못 박겠다. 항공 2인 왕복 + 1박 + 렌터카를 실비로 청구하는 구조라면 40~80만 추가가 상식적인 범위지만 **이건 추정이고, 업체마다 다르다.** 꼭 문의해서 확인할 것.

여기에 별도로 붙는 것:
- 헬퍼 25만 (야외·지방이면 +5만~)
- 헤어·메이크업 + 얼리스타트 11만~ (지방 예식/촬영은 새벽 스타트가 흔함)
- 드레스: 스튜디오 토탈이 아니면 단독 대여 22만~ / 외부 반입 11만

## 7. 스드메 표에 있는 스튜디오 — 정찰제 공개 여부 전수 조사

9월 표에 이름이 올라온 스튜디오 23곳(라흐/아카이브B를 나누면 24곳) 전부를 확인했다.

### 7-3. 정찰제 vs 패키지가 — 라흐로 교차검증

라흐는 자기 정찰제와 다이렉트 패키지가를 둘 다 볼 수 있는 유일한 케이스다.

- 라흐 자체 **B-Type 198만**(4시간·드레스 3벌·헤메 포함·원본+수정본 **포함**) + 헬퍼 25만 = **223만**
- 다이렉트 **195만 패키지** + 원본+수정본 44만 + 헬퍼 25만 = **264만** (단, 여기엔 **본식** 드레스·헤메가 함께 들어있다)

구성이 달라 1:1 비교는 무리지만, **"패키지가 - 44만(데이터) - 50만(헬퍼 촬영+본식)"을 먼저 빼고 보는 습관**은 확실히 유효하다. 표 하단에도 *불포함: 원본데이터, 헬퍼비, 본식사진, 드레스피팅비, 부케*라고 적혀 있다.

## 8. 야외스냅 문의할 때 물어볼 것

1. **출장비가 표로 있나요, 실비인가요?** (표가 있으면 대부분 권역 고정가)
2. 그 지역까지 **작가 몇 명**이 가나요? (2인이면 출장비도 2인분일 수 있음)
3. **제주/도서 지역은 항공·숙박을 실비로 청구하나요, 정액인가요?** 전날 입도가 필요한가요?
4. **원본·수정본이 촬영비에 포함인가요?** (라흐처럼 44만이 별도 필수인 곳이 많다)
5. 세부보정 몇 장, 색감보정 몇 장, **수정 횟수 몇 회**인가요?
6. 장소 몇 곳까지, **장소 간 이동시간이 촬영시간에 포함**인가요?
7. **헤어·메이크업·의상 포함인가요?** (야외스냅 상품은 거의 불포함이 기본)
8. 헬퍼가 필요한 드레스인가요? 야외라서 헬퍼비가 올라가나요?
9. **우천 시** 정책 — 연기 가능한가요, 위약금은?
10. **초상권(SNS 활용) 동의 시 할인**이 있나요? (제주 업체는 2~5만 차이, 강산픽은 5만)
11. VAT 포함인가요 별도인가요?
12. 취소·연기 위약금 구간 (예: 로에빈 60일 전 20% → 15일 전 80%)
